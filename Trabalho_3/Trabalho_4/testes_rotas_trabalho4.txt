

TESTE 1: Cadastrar um Livro Novo (Dispara: publicar_produto_novo)
curl -X POST http://127.0.0.1:8000/loja/produtos/livro \
-H "Content-Type: application/json" \
-d '{
  "codigo": "LIV001",
  "titulo": "O Senhor dos Aneis",
  "preco": 49.90,
  "autor": "J.R.R. Tolkien",
  "paginas": 1200,
  "editora": "Martins Fontes",
  "ano_publicacao": 1954
}'

TESTE 2: Atualizar o Preco do Livro (Dispara: sebo:produto:atualizado)
curl -X PATCH http://127.0.0.1:8000/loja/produtos/LIV001/preco \
-H "Content-Type: application/json" \
-d '{
  "novo_preco": 55.00
}'




TESTE 1: Adicionar o Livro ao Carrinho (Dispara: sebo:carrinho:alterado)
curl -X POST "http://127.0.0.1:8000/carrinho/adicionar/LIV001?quantidade=2"

TESTE 2: Limpar/Finalizar Carrinho com Itens (Dispara: publicar_carrinho_finalizado)
curl -X POST http://127.0.0.1:8000/carrinho/limpar




TESTE 1: Efetuar Login de Usuario (Dispara: publicar_usuario_logado)
curl -X POST http://127.0.0.1:8000/usuarios/login \
-H "Content-Type: application/json" \
-d '{
  "username": "admin",
  "senha": "admin123"
}'

TESTE 2: Efetuar Logout de Usuario (Dispara: publicar_usuario_deslogado)
curl -X POST http://127.0.0.1:8000/usuarios/logout/admin
